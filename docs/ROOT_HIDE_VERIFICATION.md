# 首轮 RootHide 功能验证候选

## 范围与身份

- 原始导入基线：`fdec1f88ebe04907ca646040166a21b76bbe1141`。
- 候选分支：`candidate/roothide-readiness`；正式 `main` 不在本轮修改范围。
- 仅构建 RootHide，不构建 Rootless，不发布 Release、不创建标签或 PR。
- 保留包标识 `com.antonym.glint`、Debian 版本 `1.6.3`、原图标与原分析附件。
- 这是功能验证候选，不是仅记录日志的诊断包，也不是已获实机验收的正式版本。
- 与原 Glint 使用相同包标识，安装会替换原包；请先准备原包及可禁用 SpringBoard 注入的恢复方式。

## 本轮修正

- 移除误写入源码的 `.cxx_destruct`，由 ARC 管理析构。
- 修正子类重复声明继承 ivar、声明顺序、参数类型、CGPoint/CGRect 混用及符号配置调用。
- 修正时钟渲染 guard 方向，避免吞掉插件自己的绘制写入。
- 解除布局函数与场景移动函数之间的直接递归。
- 补齐缺失 `GLTUnlocks` 的功能实现，保持原偏好 domain、键名和 BOOL 状态参数。
- 在安装 Hook 前检查目标类、方法及 ABI；不满足条件则保留原生行为。
- Overlay 未就绪、无可见时钟、禁用或锁屏时，不吞掉原生音量/通知路径；锁屏关闭卡片并清除临时通知内容。
- 禁用/锁屏时停止每秒数据采样，按需查询设备及闹钟；框架句柄只打开一次。未测量实际内存、CPU、帧率或耗电收益。

## 首测保护

- 新安装且没有旧偏好值时，主开关、自动媒体、设备连接、通知替换及音量替换默认关闭。
- 不清除已有偏好。旧版本保存过的开关会保留；升级测试前请自行确认其状态。
- 构建明确启用 `GLINT_VERIFICATION_BUILD=1`：禁止真实消息提交及提醒事项完成写入。
- 天气仅使用显式填写的城市；不自动请求定位，不改写宿主定位授权状态。
- 消息、日历/TCC、真实通知、媒体/设备私有 API 的完整适配不在首轮通过声明中。
- `GLTUnlocks` 的 1→0 计数及偏好契约有附件依据；跨多日、缺失日期及回拨时采用保守恢复策略：保存日恰为昨日才搬移旧 today，否则清零昨日计数。此分支策略、刷新通知目标及错误防御是重建实现，未证明与原二进制逐分支等价。

## 构建及证据

- 云端：GitHub Actions `macos-15`、Xcode 16.4、iPhoneOS SDK 18.5。
- 工具链：固定 `roothide/theos@3ac89c984ec652fd16bcd91b33ae16de45ce76fa` 及其子模块。
- Preferences 链接使用固定 SDK 仓库中的单个 `.tbd`，下载后核对 SHA-256；不复制整个旧 SDK，不冒充新的部署目标。
- 本地 Python 检查只证明源代码契约及校验器负例；macOS Foundation replay 执行实际 ABI helper 与解锁计数实现，不能证明 UIKit/SpringBoard 行为。
- 唯一候选分支的 push 启动一个 RootHide job；保留源码 SHA、工具链日志、主机构建输出、原始 deb 及独立包校验报告，失败同样上传证据。
- 包校验包括标识/版本/路径、资源、每个 Mach-O 的 arm64/arm64e、设备平台/最低系统版本、签名结构及代码页哈希。结构签名不证明签名信任或设备兼容性。
- 本文写入时尚未获得云构建或真机结果；以 exact-SHA run、原始附件及后续用户实测为准。

## 真机验收顺序

1. 先确认恢复路径，再安装并检查能否正常进入桌面、设置页能否打开、默认开关是否符合上述新/旧配置边界。
2. 先只启用时间显示，检查无重启/卡死，状态栏、点击区域、展开/关闭、横竖屏、前后台及锁屏/解锁正常。
3. 检查锁屏不显示插件敏感内容，原生音量和通知不会因插件未就绪而消失。
4. 再单独测试解锁计数：首次启动不加一、重复未解锁通知不加一、一次真实锁屏→解锁只加一；跨日及重启持久化另行验证。
5. 最后才逐项验证媒体、固定城市天气、日历等读取功能；本包不用于发送真实消息或完成真实提醒事项。
6. 分别记录 iOS 15.4.1 与 iOS 16.0.3 的设备/越狱环境结果。任一设备失败先保留证据，不能用 CI 或另一设备的通过结果替代。
